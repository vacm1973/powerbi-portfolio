# 📂 Power Query (M Language) ETL Workflows

This directory contains Power Query transformation scripts used to clean, filter, and structure raw source data before loading it into the Power BI semantic model.

## 📄 Included Files & Technical Rationale:

* **[`advanced_etl_pipeline.pq`](./advanced_etl_pipeline.pq)**: Advanced M transformation pipeline implementing dynamic unpivoting, null value imputation, custom profitability tiers, and string normalization for dimensional star-schema modeling.
